# Laporan perorangan — Melinza Nabila (123450122), jalur tl

- **Peran**: Penjaga Data & Evaluasi + Penanggung Jawab Jalur Transfer Learning (`tl`).
- **Status**: Sprint 0 & Sprint 1 (diuji pada data simulasi dummy `data/sesi_simulasi/`; siap dijalankan ulang saat data primer meja tersedia).

## 1. Komponen saya
Saya bertanggung jawab atas protokol pemuatan data (`src/protokol/data.py`, `src/protokol/PROTOKOL.md`), pembanding non-deep learning (`src/protokol/pembanding_rf.py`), serta jalur model **Transfer Learning (`models/123450122/run.py`)** berbasis `ResNet-18` pralatih ImageNet-1K yang diadaptasi melalui spektrogram log-STFT 7-kanal dan adapter `Conv2d(7, 3, 1)`.

## 2. Keputusan desain
Untuk menjembatani sinyal sensor 1D multi-kanal (`[N, 400, 7]`: 6 aksis IMU MPU6050 400 Hz dan arus kipas 200 Hz yang diinterpolasi ke 400 Hz) ke backbone penglihatan 2D `ResNet-18`, sinyal diubah menjadi spektrogram log-STFT berukuran `64×64` lalu dipetakan oleh adapter `Conv2d(7, 3, kernel_size=1) + BatchNorm2d(3)`. Alternatif mengurangi kanal menjadi 3 secara manual (`||acc||, ||gyro||, arus`) ditolak untuk konfigurasi awal karena membuang informasi arah sumbu getaran, dan lapisan awal `conv1`–`layer2` dibekukan agar fitur pralatih tetap stabil pada dataset berjumlah terbatas.

## 3. Kegagalan dan pelajaran
Pada percobaan awal impor `torch` setelah `numpy`/`pandas` di Windows menimbulkan galat inisialisasi DLL (`WinError 1114` pada `c10.dll`), sehingga urutan impor pada `run.py` diubah agar `torch` dimuat paling awal. Selain itu, baseline regresi logistik domain waktu hanya mencapai `val_macro_f1 = 0.216055` karena fase gelombang getaran bergeser antar-jendela 1 detik; mengubah sinyal ke domain waktu-frekuensi (STFT untuk TL dan fitur statistik + FFT untuk Random Forest) langsung menaikkan `val_macro_f1` hingga `0.988044` (TL) dan `1.000000` (RF).
